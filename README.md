# Dead's Mod — Requiem (Forge 1.16.5)

Экспериментальный единый мод **horrormod 1.0.0** для клиента и выделенного сервера Minecraft Forge 1.16.5.

Содержимое репозитория:
- Java 8 hooks и настройки генерации в `src/main/java/net/mcreator/horrormod/unified/`;
- ASM-патчер оригинального JAR в `tools/PatchJar.java`;
- GitHub Actions в `.github/workflows/build.yml`.

## Сборка GitHub Actions
Исходный `original.jar` (около 63 МБ) намеренно не выкладывается в публичный исходный код: в нём есть сторонние аудиофайлы. Если права на распространение не подтверждены, **сначала сделайте репозиторий приватным**.

1. Откройте **Releases → Draft a new release**. Тег: `original-input-v1`.
2. Прикрепите **оригинальный** `Dead's Mod (Client).jar`, переименованный в `original.jar` (не Requiem).
3. Опубликуйте release — начнётся сборка. Либо используйте вкладку **Actions → Run workflow**.
4. После успешного выполнения скачайте **Artifacts → DeadsMod-Requiem-build**.

Результат включает JAR Forge 1.16.5 и ZIP с декомпилированными исходниками, оригинальным JAR и изменёнными Java-файлами.

## Исправления и ограничения
Два исходных JAR оказались побайтно одинаковы по 1508 записям, поэтому используется одна база. Добавлены ограничители генерации данжей (шаги сетки 48/96/112 чанков), ванильный компас мёртвых с NBT-маркером и вход на обсидиановую площадку в измерении `horrormod:secretdim`.

**Экспериментальная версия:** полноценная загрузка на клиенте и выделенном сервере Forge пока не проверена. Компас указывает на *расчётную позицию* структуры, не гарантируя, что данж существует. Генерация старых чанков не пересчитывается. Сделайте резервную копию мира.

Для запуска — Java 8, для офлайн-патчера — JDK 21. Исходники оригинального MCreator-проекта недоступны; они восстанавливаются из JAR при CI.
